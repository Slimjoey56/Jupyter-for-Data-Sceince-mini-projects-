# Python and Data Science — Jupyter Mini Projects

A collection of practical Jupyter notebooks used to explore Python programming, data handling, APIs, file formats, and introductory data analysis.

| Topic | Example notebook |

## Getting Started

**Requirements:** Python 3, Jupyter Notebook, and the libraries imported by the notebook you choose.

```bash
jupyter notebook
```

Open a notebook from the file browser and execute its cells in order. Several notebooks use sample CSV, JSON, XML, text, and spreadsheet files included in this repository.

## Purpose

This is a learning archive. The notebooks are independent exercises, not components of one production data pipeline.
